# Новая главная страница nenlib.ru

Интерактивный прототип обновлённой главной страницы сайта **Ненецкой центральной библиотеки имени А. И. Пичкова**.

> Проект предназначен для демонстрации и согласования концепции. Это не готовая замена действующего сайта и не содержит интеграции с Joomla, J-ИРБИС или серверной базой данных.

## Возможности прототипа

- адаптивная вёрстка для компьютеров, планшетов и телефонов;
- основное меню и мобильная навигация;
- главный информационный слайдер;
- быстрый доступ к каталогу, афише и онлайн-услугам;
- переключение новостей центральной библиотеки и филиалов;
- блок событий и актуальной информации;
- поиск по действующему сайту;
- демонстрационный режим для слабовидящих.

## Технологии

Проект не требует сборки и внешних JavaScript-зависимостей:

- HTML5;
- CSS3;
- JavaScript.

## Структура

```text
.
├── assets/       # фотографии и графические материалы
├── index.html    # главная страница
├── styles.css    # оформление и адаптивная вёрстка
├── app.js        # интерактивные элементы
├── favicon.svg   # значок сайта
└── vercel.json   # настройки размещения на Vercel
```

## Локальный запуск

Можно открыть `index.html` непосредственно в браузере или запустить простой локальный сервер:

```bash
python -m http.server 8000
```

После запуска страница будет доступна по адресу `http://localhost:8000`.

## Размещение на Vercel

1. В Vercel выбрать **Add New → Project**.
2. Импортировать репозиторий `ardeev1999/newNenlib`.
3. В поле **Framework Preset** выбрать `Other`.
4. Оставить корневую папку проекта `./`.
5. Команды сборки и выходной каталог не указывать.
6. Нажать **Deploy**.

Последующие изменения в ветке `main` будут автоматически публиковаться Vercel.

## Важные замечания

- Часть ссылок ведёт на разделы действующего сайта [nenlib.ru](https://nenlib.ru/).
- Тексты, даты и материалы в прототипе необходимо проверить перед промышленным запуском.
- Для рабочего сайта потребуется отдельная интеграция с новой CMS, электронным каталогом и формами обратной связи.
